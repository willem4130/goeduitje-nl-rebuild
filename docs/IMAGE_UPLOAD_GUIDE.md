## Via Admin Paneel (goeduitje-backend.vercel.app)

### Workshop Afbeeldingen

De volgende afbeeldingen kunnen via het admin paneel worden aangepast onder **Workshops**:

| Workshop       | Huidige foto           | Nieuwe foto (aangeleverd)                                    |
| -------------- | ---------------------- | ------------------------------------------------------------ |
| Kookworkshop   | kookworkshop.jpg       | `onze-uitjes_kookworkshops.jpg` → upload als workshop image  |
| Stadsspel      | (video, geen fallback) | `onze-uitjes_stadsspel.jpg` → upload als workshop image      |
| The Game       | the-game.jpg           | `onze-uitjes_the game.jpg` → upload als workshop image       |
| Koffie & Thee  | koffie-thee.jpg        | `onze-uitjes_koffie&thee.jpg` → upload als workshop image    |
| Beachvolleybal | beachvolleybal.jpg     | `onze-uitjes_beachvolleybal.jpg` → upload als workshop image |
| Lunch & Diner  | ⚠️ ONTBREEKT           | `onze-uitjes_lunch&diner.jpg` → upload als workshop image    |

**Stappen:**

1. Ga naar het admin paneel → Workshops
2. Klik op de workshop die je wilt aanpassen
3. Upload de nieuwe afbeelding in het "Image" veld
4. Klik op "Save"
