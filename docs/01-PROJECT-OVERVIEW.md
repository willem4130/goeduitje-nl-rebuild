# Project Overview

> **Goeduitje.nl** - A comprehensive platform for booking activities and experiences

---

## 🎯 What is Goeduitje.nl?

Goeduitje.nl is a modern web platform that allows customers to discover, book, and enjoy various activities and experiences. The platform provides a seamless booking experience, comprehensive activity information, and easy-to-use management tools for administrators.

## 🏗️ Technical Overview

### Platform Type

Full-stack web application with:

- Server-side rendering (SSR)
- Static site generation (SSG) where applicable
- Client-side interactivity
- Progressive Web App (PWA) capabilities

### Core Technologies

- **Frontend**: Next.js 16, React 19, TypeScript
- **Styling**: Tailwind CSS 4, shadcn/ui
- **Backend**: tRPC, Prisma ORM
- **Database**: PostgreSQL
- **Hosting**: Vercel
- **Email**: Resend
- **Payments**: Stripe (optional)
- **Booking**: Cal.com integration

### Key Characteristics

- **Fast**: Optimized for performance
- **Secure**: Built with security best practices
- **Scalable**: Can grow with business
- **Maintainable**: Clean code, well-documented
- **SEO-friendly**: Optimized for search engines
