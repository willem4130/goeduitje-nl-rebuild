## Mapping to Tailwind CSS

Once colors are extracted, map them to Tailwind CSS variables:

```css
/* Add to globals.css */
:root {
  --primary: [oklch values];
  --primary-foreground: [oklch values];
  --secondary: [oklch values];
  --background: [oklch values];
  --foreground: [oklch values];
  /* ... etc */
}
```

**Conversion Tool**: Use https://oklch.com to convert hex to oklch for better color manipulation
