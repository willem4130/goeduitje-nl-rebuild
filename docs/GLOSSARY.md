# Glossary

> **Common terms and abbreviations used in the project**

---

## A

**App Router** - Next.js's new routing system using the `app/` directory

**API** - Application Programming Interface

---

## C

**CMS** - Content Management System

**CLS** - Cumulative Layout Shift (Core Web Vital)

**Component** - Reusable React UI element

**Core Web Vitals** - Google's metrics for web performance (LCP, INP, CLS)

**CRUD** - Create, Read, Update, Delete

**CSS** - Cascading Style Sheets

**CSR** - Client-Side Rendering

---

## E

**E2E** - End-to-End (testing)

**ESLint** - JavaScript/TypeScript linting tool

---

## G

**GEO** - Geographic/Local SEO

---

## H

**Hook** - React function for state and lifecycle (useState, useEffect, etc.)

---

## I

**INP** - Interaction to Next Paint (Core Web Vital)

**ISR** - Incremental Static Regeneration

---

## J

**JSON-LD** - JavaScript Object Notation for Linked Data (structured data format)

---

## L

**LCP** - Largest Contentful Paint (Core Web Vital)

**LQIP** - Low Quality Image Placeholder

---

## M

**Metadata** - Information about a web page (title, description, etc.)

**Middleware** - Code that runs between request and response

---

## N

**NAP** - Name, Address, Phone (local SEO term)

---

## O

**OG** - Open Graph (social media meta tags)

**ORM** - Object-Relational Mapping (Prisma)

---

## P

**Prisma** - TypeScript ORM for databases

**Props** - Properties passed to React components

---

## R

**RSC** - React Server Components

---

## S

**SEO** - Search Engine Optimization

**SSG** - Static Site Generation

**SSR** - Server-Side Rendering

**Schema** - Structured data format for search engines

---

## T

**tRPC** - TypeScript Remote Procedure Call (type-safe APIs)

**TypeScript** - Typed superset of JavaScript

---

## U

**UI** - User Interface

**UX** - User Experience

---

## V

**Vercel** - Hosting platform for Next.js apps

---

## W

**WCAG** - Web Content Accessibility Guidelines

---
